// MANIFESTO

PMX OS is a complete desktop operating system built around one idea: the internet should belong to the people on it. No cloud. No telemetry. No boss. It’s the native home for everything PANMOX — and it’s unmistakably ours from the moment it boots.

// 01 · WHAT IT IS

An OS that’s unmistakably ours.

A complete desktop. Not a fork. Not a theme. An operating system with its own face, its own front door, and PANMOX in its bones from the moment it boots.

// 02 · BUILT ON

The hard parts, done right.

Debian — the most trusted, security-maintained Linux base there is — with a KDE Plasma desktop rebuilt into something purely PMX. UEFI and BIOS. Live from USB. Installs to disk when you’re ready.

// 03 · THE ONE APP THAT SHIPS WITH IT

AltNet Studio, in the box.

The first PANMOX app to come pre-installed. Run a node, or claim a .alt name, the moment you boot. More of the catalog joins in future versions.

// 04 · TWO FACES, ONE OS

Flip to phosphor.

One click swaps the whole desktop from deep-cyan to retro phosphor-green. Wallpaper, dock, accents — the lot. Try the toggle in the corner of this page.

// INSTALL

Onto a USB in one flow.

LinuxSimplify · PMX is the official installer. It scans your hardware, downloads the newest PMX OS release, and flashes it to a USB drive — ready to boot and install. No terminal gymnastics, no hunting for ISOs.

↓ Download for Windows .exe · x64 ↓ Download for Linux x64
v1.0.0 · GPL v3 · Windows 10/11 · admin rights for flashing
1

Scan your hardware.

Slide to detect CPU, RAM, GPU, storage and boot mode — so you know what to expect before you start.

2

Download PMX OS.

Always grabs the newest release from GitHub. Handles split ISOs automatically and verifies the SHA-256 checksum.

3

Flash the USB.

Raw flashing like dd or Rufus. Auto-detects the drive when you plug it in, then cleans up the ISO when it’s done.

4

Boot & install.

Disable Secure Boot, pick the UEFI USB entry, and install. Live first, then to disk when you’re ready.

Linux — run as a normal user
# make it executable, then launch
chmod +x LinuxSimplify-PMX-linux-x64
./LinuxSimplify-PMX-linux-x64
# a pkexec prompt appears when flashing
Heads up

On Windows, SmartScreen may warn about an unrecognized app — click More info → Run anyway. Full steps live in release/HOW-TO-INSTALL.md in the repo.
